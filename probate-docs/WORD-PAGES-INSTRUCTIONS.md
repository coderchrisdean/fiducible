# Step-by-Step Word / Pages (iPad) Formatting Instructions

## MICROSOFT WORD (Mac / PC / iPad)

Work through these steps **in order** on a blank new document before pasting content.

---

### STEP 1 — Page Size

**Mac/PC:**
1. Layout tab → Size → **Letter (8.5 × 11 in)**

**iPad (Word):**
1. Tap the **pencil icon** (Edit) → tap **Home** dropdown → **Layout**
2. Tap **Page Size** → select **Letter**

---

### STEP 2 — Margins

**Mac/PC:**
1. Layout tab → Margins → **Custom Margins…**
   - Top: **1.0"**
   - Bottom: **1.0"**
   - Left: **1.5"** *(extra space accommodates line numbers; text stays ≥1" from edge)*
   - Right: **0.5"**
2. Click OK.

**iPad (Word):**
1. Layout → **Margins** → Custom
   - Top 1", Bottom 1", Left 1.5", Right 0.5"

---

### STEP 3 — Font

**Mac/PC:**
1. Select All (Cmd+A / Ctrl+A)
2. Home tab → Font: **Times New Roman**, Size: **12**

**iPad:**
1. Select All → tap **A** (font) → Times New Roman, 12 pt

---

### STEP 4 — Line Spacing (Double)

**Mac/PC:**
1. Select All → Home → Line Spacing → **2.0** (Double)
   - OR: Paragraph dialog → Line spacing: Double, Before: 0 pt, After: 0 pt

**iPad:**
1. Select All → Home → Paragraph → Line spacing → **2**

---

### STEP 5 — Line Numbers (Critical for California Pleading)

**Mac/PC:**
1. Layout tab → **Line Numbers** → **Continuous**
   - Check: "Restart each page" — set to **Restart Each Page** so lines number 1–28 per page
   - Count by: **1**
   - From text: **0.25"** (positions numbers in left margin between 0.5"–0.75" from page edge)

**iPad (Word for iPad):**
1. Tap **Layout** → **Line Numbers** → **Continuous** *(if not visible, use Desktop Mode or do this step in Word on Mac/PC)*

> **Note:** If Word on iPad doesn't show Line Numbers, complete this step in the desktop version or use a California Pleading Paper template (see Step 5a below).

**Step 5a — Alternative: Use a California Numbered Pleading Template**
- Google: "California pleading paper template Word" — download a pre-numbered 28-line template.
- Paste your formatted text into the template instead of setting up line numbers manually.
- Free templates available at calbar.ca.gov and many county law library websites.

---

### STEP 6 — Footer (Required on Every Page Except Exhibits)

**Mac/PC:**
1. Insert tab → **Footer** → **Edit Footer**
2. Insert → **Horizontal Line** (or type a row of underscores: `___...___` spanning the page)
3. Press Enter, type the short title:
   ```
   NOTICE OF MOTION AND MOTION TO DISQUALIFY COUNSEL — Case No. 23STPB13044
   ```
4. Select footer text → set font to **Times New Roman, 10 pt**, centered.
5. Check "**Different First Page**" only if you want to suppress footer on page 1 *(not required; footer may appear on page 1)*.
6. Close Header & Footer.

**iPad (Word):**
1. Tap **Insert** → **Header & Footer** → **Footer**
2. Type the horizontal rule line and short title as above.
3. Set font to 10 pt.

---

### STEP 7 — Page Numbers

**Mac/PC:**
1. Insert tab → **Page Number** → **Bottom of Page** → **Plain Number 2** (centered)
2. The page number should appear **above** the footer rule and short title.
   - To achieve this order: page number first in footer, then horizontal rule, then short title.
3. In Header & Footer mode: click just before the horizontal rule → Insert → Page Number → Current Position.

**Correct footer layout (bottom up on printed page):**
```
[Short Title — 10 pt]
[Horizontal Rule]
[Page Number — centered]
```

**iPad:**
1. Insert → Page Number → Bottom Center.

---

### STEP 8 — First-Page Caption (CRC 2.111 Two-Column Layout)

The first-page caption requires a **left column** (filer info) and a **right blank area** (≥2" wide for clerk's stamp). Use a table:

**Mac/PC:**
1. At the top of page 1, insert a **2-column, 1-row table**:
   - Insert → Table → 2×1
   - Left column width: **3.5"**
   - Right column width: **2.5"** (this is the clerk stamp area — leave blank)
2. Remove table borders: Table Design → Borders → **No Border**
3. In left cell, type:
   ```
   DEVONGE CHRISTOPHER DEAN
   P.O. Box 83582
   Los Angeles, CA 90083
   coderchrisdean@protonmail.com
   T: 424-345-4299

   Objector, Co-Conservator, and
   Interested Person, In Pro Per
   ```
4. Right cell: leave completely blank (clerk stamps here).
5. Below the table (line ~9–10, approximately 3⅓" from top), type the court name centered:
   ```
   SUPERIOR COURT OF THE STATE OF CALIFORNIA
   COUNTY OF LOS ANGELES — PROBATE DIVISION
   ```

**iPad:**
- Use the same table approach: Insert → Table → 2 columns, 1 row.

---

### STEP 9 — Case Title and Case Number (Two-Column)

Below the court name, insert another **2-column table** (no borders):
- Left cell: `In re Durable Power of Attorney of DOCK DEAN, Conservatee.`
- Right cell: `Case No. 23STPB13044` / `Related: 24STPB01681`

Then center the document title below in **bold, all caps**:
```
NOTICE OF MOTION AND MOTION TO DISQUALIFY COUNSEL
```

---

### STEP 10 — Hearing Block

After the document title, left-aligned, tabbed:
```
Hearing Date:   May 22, 2026
Time:           9:30 a.m.
Department:     67
Judge:          Hon. Daniel Juarez
```

Use **Tab stops** at 1.8" for consistent alignment.

---

### STEP 11 — Body Text Indentation

Per California pleading convention:
- First line of each paragraph: indent **0.5"** (Tab key once)
- Block quotations (if any): indent **1"** both sides, single-spaced
- Numbered grounds headings: **Bold**, use outline numbering (1., 2., 3., 4.)

---

### STEP 12 — Signature Block

Approximately 4 blank lines above the signature line:
```
DATED:  ____________________________


________________________________________
DEVONGE CHRISTOPHER DEAN
In Pro Per / Co-Conservator / Objector / Interested Person
```

Leave **4 blank double-spaced lines** between "DATED" and the signature line for handwritten date and signature.

### STEP 13 — Export to PDF (for e-Filing)

**CRITICAL — Do not skip:**

**Mac/PC (Word):**
1. File → **Save As** → change format to **PDF**
   - OR: File → **Export** → **Create PDF/XPS**
2. In the PDF options dialog, ensure:
   - "**Optimize for: Standard**" (not minimum size)
   - "**ISO 19005-1 compliant (PDF/A)**" — check this box if available (best for court filing)
3. Do **NOT** password-protect or restrict editing in the PDF.
4. Do **NOT** save fillable form fields — flatten all content.

**iPad (Word):**
1. Tap **…** (more options) → **Export** → **Send a Copy** → **PDF**
2. Email or AirDrop the PDF to yourself, then upload to LA Superior Court eFiling portal.

**Verify the PDF:**
- Open in Adobe Acrobat Reader → Edit → Find (Ctrl+F) → search for a word from the document.
- If it finds the word: ✅ text-searchable (court-compliant).
- If it doesn't find it: ❌ image-only — re-export from Word (do not scan a printout).

## PAGES (iPad) — ALTERNATE INSTRUCTIONS

Pages does not support line numbering natively. Use this workaround:

### Option A — Manual Line Numbers (Simplest)
1. Format your document in Pages for all other settings.
2. Export to Word (.docx): Tap **…** → **Export** → **Word**
3. Open the .docx in **Word for iPad** or on a Mac → add line numbers there (Step 5 above).

### Option B — Two-Column Table Trick
- Create a narrow left column (0.3") and a wide right column (5.7").
- Type line numbers 1–28 manually in the left column cells.
- Type the pleading text in the right column.
- (Labor-intensive; Option A is recommended.)

### Pages Settings (all other rules):
| Setting | Value | Path in Pages (iPad) |
|---------|-------|----------------------|
| Page Size | 8.5 × 11 in | Document → Page Size → US Letter |
| Margins | L:1.5" R:0.5" T:1" B:1" | Document → Document Margins |
| Font | Times New Roman 12 pt | Format → Font |
| Line Spacing | 2.0 (Double) | Format → Spacing → Lines → 2 |
| Footer | Short title + rule | Insert → Headers & Footers → Footer |
| Page Numbers | Bottom center | Insert → Page Number → Footer |

## PROBATE-SPECIFIC ADDITIONS

### PDF Bookmarks (for Declaration + Exhibits)
When filing the Declaration with exhibits, add PDF bookmarks:
- "Exhibit A — [Description]"
- "Exhibit B — [Description]"
- etc.

In **Adobe Acrobat:**
1. View → Navigation Panels → Bookmarks
2. Right-click → New Bookmark at the first page of each exhibit
3. Name each bookmark "Exhibit A," "Exhibit B," etc.

In **Preview (Mac):**
- Open sidebar (View → Thumbnails) → drag to locate exhibit page → right-click page → Add Bookmark.

### Exhibit Index Page
Insert a page before the exhibits listing:
```
EXHIBIT INDEX

Exhibit A:  [Description]............................Page __
Exhibit B:  [Description]............................Page __
Exhibit C:  [Description]............................Page __
```
